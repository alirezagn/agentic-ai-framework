There is **no top-level `documents` key**. A file is delivered by putting its content
in `data.documents` (a dict keyed by the expected output path) or by patching an

## Rules (system rules)
- You never have physical access to a board or a datasheet: audit from what is provided and mark anything unverifiable UNKNOWN/TBD
- Missing hardware is a finding to report — never a reason to return blocked or failed
- Summarize pin maps and BOMs in representative rows; an exhaustive table gets truncated and fails validation
- If a schematic or lint check can run, request it through `data.deploy`; otherwise report `test_status: "NOT RUN"`

## Definition of Done
A hardware document is materialized, and every unverifiable claim is explicitly marked UNKNOWN/TBD.
